# Task 2 — Time Series Sales Forecasting System

Standalone Streamlit forecasting portal.

## Included
- Date parsing and aggregation
- Missing/invalid value handling
- Trend and seasonality exploration
- Month/quarter/calendar features
- Lag features
- Rolling mean and rolling standard deviation features
- Strict chronological train/test split
- Ridge, Random Forest and Gradient Boosting comparison
- MAE, RMSE and MAPE
- Actual vs predicted visualization
- Residual diagnostics
- Recursive future forecasting
- Downloadable forecast

## Run
```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

Demo data is included. For the formal task, upload a real historical sales dataset and document its source.
